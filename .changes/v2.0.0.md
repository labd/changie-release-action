## v2.0.0 - 2026-10-26
### Added
* Add goreleaser action that publishes as draft, uploads assets and then publishes the release
* Add create-release input to create a GitHub release with the changie notes
* Add pypi action that builds with uv, publishes with trusted publishing and then creates the GitHub release
### Changed
* Removed the release-workflow input: the action tags the release and sets the released, version and notes-file outputs so publishing happens in the same job
* Release PR uses a fixed changie-release/<branch> branch, so a version change updates the existing PR instead of opening a second one
### Fixed
* GitHub release notes were empty
